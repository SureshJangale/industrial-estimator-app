# Yash Engineering quotation identity, contact and dual export

**Seller:** YASH ENGINEERING. Default office/works/GSTIN/contact are transcribed from the company's supplied quotations. They may be edited per quotation by authorized personnel. The source spelling is retained pending confirmation.

**Customer contact:** entered for each quotation, **Kind Attendance**. Do not populate `customer_attention` with a customer's department or reuse a previous customer's named contact. The app rejects missing/invalid names before generating PDF, Word or issuing a firm quotation. It remains the estimator's responsibility to confirm the correct recipient.

**Output:**

- Built-in Quote 73 PDF: fixed A4 coordinates, table columns and ruled cells. This is the fidelity reference.
- Built-in Quote 73 Word: editable document carrying the same data. It aims for the same one-page structure but not pixel-level parity; rendering depends on the local Word processor and fonts.
- Admin-uploaded DOCX quotation templates: Word download uses the selected template and its supported placeholders.
- JSON quotation formats: Word download uses the generic editable customer-facing layout; the PDF follows the selected JSON format.

**Where to get downloads:** quotation header -> **View quotation PDF** or **Download editable Word**, or the **Customer quotation** tab. After commercial issue, **History** offers the archived PDF and Word files separately.

**Do not confuse uploads:** **Quote formats** is for an admin-uploaded quotation output template; the **Documents** second tab is for technical source drawings/specifications and extraction only.

**Correction workflow:** edit the current project fields, regenerate PDF/DOCX, review, obtain approvals, issue a new revision. Editing a downloaded DOCX does not change a frozen issued PDF or update calculation/verification records.

**Security:** do not publish private customer drawings or real quotations to a public repository. Seller details are intended for the company's output; the supplied historical customer names are not part of the distributed sample data.
